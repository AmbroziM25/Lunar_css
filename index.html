Lunara CSS

A lightweight, utility-first CSS framework with a dark night-sky aesthetic — deep space navys, moonlight whites, and soft indigo/violet glow. Pure CSS, zero build step, drop-in Tailwind preset.

Scroll-driven motion

Pure-CSS scroll animations via animation-timeline — zero JavaScript, no IntersectionObserver. Scroll down and back up: the reveal scrubs with you. The bar at the very top of this page is one element: .scroll-progress. Browsers without support simply show content normally.
